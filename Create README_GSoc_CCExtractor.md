# GSoC 2025 - CCExtractor OCR Unit Tests
This repository contains initial exploration and testing for the OCR module in CCExtractor, as part of my GSoC 2025 proposal.

## Objective
To write robust unit tests for the OCR module of CCExtractor in both C++ and Python, improve test coverage, and integrate the suite with GitHub Actions.

## Deliverables
- C++ unit tests using Catch2 or Google Test
- Python wrapper tests
- GitHub Actions for CI
- Test plan documentation
